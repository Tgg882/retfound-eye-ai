# 测试工程规划

本目录预留给后续测试。目前不创建测试代码、测试依赖或真实医疗数据样本。

## 规划范围

- 单元测试：输入校验、任务状态、错误处理及数据转换。
- 接口与集成测试：前后端契约、模型服务和知识服务交互。
- 验收测试：需求编号、可重现步骤、预期输出与人工复核。
- 模型验证：输入范围、数据来源、版本、评价方法和局限性，待实验设计确认。

## 记录约定

测试记录应包含环境、命令、退出码、实际输出、通过或失败结论和关联任务编号。未执行的测试明确写为“未执行”，不得以目录存在或代码生成成功替代功能验证。

使用经授权、脱敏的小型测试样例；原始数据集和模型权重存放在仓库之外。构建、问题修复和部署证据分别归档到比赛资料的对应目录。
