# 比赛资料归档规划

本目录用于归档比赛规则、需求、架构与真实开发证据。目前仅创建说明和模板，尚未提供官方赛题、正式需求或已完成的业务实现。

| 目录 | 归档用途 |
| --- | --- |
| `00_official/` | 官方规则、赛题、评审与提交要求及来源信息 |
| `01_requirements/` | 需求拆解、验收标准和待确认事项 |
| `02_architecture/` | 架构、接口、数据流和技术决策 |
| `03_codearts_evidence/` | 会话、截图、生成成果及贡献索引 |
| `04_code_generation/` | 代码生成任务、文件变更与证据对应关系 |
| `05_project_build/` | 环境、构建命令、输出与构建问题 |
| `06_problem_fixing/` | 问题复现、原因、修复与回归验证 |
| `07_deployment/` | 部署方案、执行记录、验收与回滚 |

## 归档规则

- 每项真实工作使用任务编号，关联需求、会话、文件变更、测试与人工验收。
- 保留来源、日期、版本和原始证据；不编造官方要求、会话、截图或验证结论。
- 严格区分 CodeArts 内置智能体、OpenAI Codex 和人工贡献；多工具协作分别记录各自实际完成的部分。
- 对外提交前检查密钥、个人信息、医学影像授权及资料许可；未经脱敏的原件保存在受控位置。

## 本次初始化来源

本次目录和模板初始化由 **OpenAI Codex** 执行，不属于 CodeArts 内置智能体开发成果。目录建立不代表模型、业务服务、构建或部署已经完成。

现有 `.codeartsdoer/` 配置保持原样。其中原有 `.gitignore` 内容为 `*`，默认忽略其内部文件；根目录仅另外排除 `.codeartsdoer/.codebase/` 本地索引和运行状态。后续如需提交配置，应逐个核对，不应强制添加整个目录或上传本地索引。
