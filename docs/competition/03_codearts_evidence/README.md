# 智能体开发证据管理

本目录用于组织真实的 CodeArts 开发证据，同时明确标识其他工具与人工贡献。目录名称不代表其中所有材料都由 CodeArts 内置智能体生成。

## 目录与入口

- [evidence_index.md](evidence_index.md)：每项证据的任务、来源、路径和审查状态。
- [conversation_template.md](conversation_template.md)：完整任务记录模板。
- [conversations/](conversations/README.md)：原始输入、完整输出和后续追问。
- [screenshots/](screenshots/README.md)：能辨认任务、工具和结果的真实截图。
- [generated/](generated/README.md)：生成成果清单、关联文件及校验信息。

## 贡献归属

| 类型 | 记录要求 |
| --- | --- |
| CodeArts 内置智能体 | 记录界面显示的智能体名称、运行位置及真实会话或截图；未知模型写“未显示” |
| OpenAI Codex | 明确写明 OpenAI Codex、执行环境及实际修改范围，不登记为 CodeArts 内置智能体成果 |
| 人工 | 记录实际操作人、修改或验收内容及日期 |

协同任务按执行工具拆分子记录，并在同一父任务下交叉链接。不能仅根据 `.codeartsdoer/` 的存在、文件所在目录或项目使用了 CodeArts 就认定贡献来源。由一个工具生成后被另一个工具修改的成果，分别记录生成与修改。

本次仓库初始化由 **OpenAI Codex** 完成。目前没有归档的有效 CodeArts 内置智能体会话证据，也没有人工验收结论。

## 归档流程

1. 从模板创建任务记录，填写真实任务编号、日期、时区及实际智能体。
2. 保留原始输入、完整输出及每轮追问；长输出拆分存档并列明顺序与路径。
3. 关联修改文件、生成成果、真实截图和测试命令及结果。
4. 人工填写验收意见，并将记录加入索引；未测试、未截图或未验收必须明确标注。
5. 公开前完成脱敏与来源审查，核对贡献归属和所有相对链接。

完整记录至少包含：任务编号、日期、使用的智能体、原始输入、完整输出、修改文件、生成成果、截图位置、测试结果、人工验收意见。

完整原件可能包含密钥或个人信息时，存放在仓库之外的受控位置，记录校验值与访问负责人；公开副本显式标注脱敏位置，不将删节副本标记为未经删节的原始输出。`private_evidence/` 与 `*.unredacted.*` 被根 `.gitignore` 排除，但仍需在提交前检查内容。
