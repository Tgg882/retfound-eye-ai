# 真实截图归档

保存能够证明实际任务、智能体身份、生成过程、测试或验收结果的截图。目前没有归档截图，不生成模拟界面作为证据。

建议命名为 `<任务编号>-<序号>-<说明>.png`，在对应会话中记录截图位置、拍摄日期与时区、工具名称和证明内容。画面应保留足够上下文，能对应到真实会话或操作。

公开前遮蔽密钥、账号隐私、患者信息与不应公开的路径，说明脱敏或裁剪范围；不得通过拼接或编辑误导贡献归属。完整原件在受控位置保存，按需记录校验值。

CodeArts 内置智能体与 OpenAI Codex 的截图按真实来源标识，不可相互替代。根 `.gitignore` 不会统一忽略 PNG/JPG 等证据图片，但每张图片仍需人工审查后再提交。
