# 生成成果归档

保存经审查的生成成果说明、小型可公开附件和任务到实际工程文件的对应关系。目前没有业务代码或模型成果。

每项成果记录任务编号、名称、实际生成工具、路径、版本或 SHA-256、后续修改者及验证状态。工程文件优先保留在其实际模块目录，通过仓库相对路径关联，避免复制多个无法同步的版本。

CodeArts 内置智能体生成、OpenAI Codex 生成和人工修改分别注明；模板或规划文档不得当作已实现功能。测试和人工验收结论必须对应真实记录。

模型权重、原始数据集、患者影像和临时实验输出不放入本目录；只记录授权范围内的来源、校验值和受控存放说明。更新 [证据索引](../evidence_index.md) 并关联完整会话和截图。
