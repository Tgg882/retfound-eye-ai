# 会话原文归档

保存真实任务的原始输入、完整输出、追问、失败及更正记录。目前没有已归档会话，不将本说明或模板视为开发证据。

从 [conversation_template.md](../conversation_template.md) 复制任务记录，使用实际任务编号命名，例如 `CA-YYYYMMDD-NNN.md` 或 `CX-YYYYMMDD-NNN.md`。按实际来源分别记录 CodeArts 内置智能体与 OpenAI Codex，人工修改另作说明。

长会话可使用 `<任务编号>-part01.md` 等有序分片，并在主记录列出全部文件、顺序和校验值。完整输出不能只保留成功片段或摘要；附加上下文注明来源和版本。

原文包含凭据、隐私或未授权材料时，完整原件存放在仓库之外的受控位置，公开副本标明脱敏位置。归档后更新 [证据索引](../evidence_index.md)，关联成果、截图、测试和人工验收。
