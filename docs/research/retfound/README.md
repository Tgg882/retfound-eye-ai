# RETFound 研究资料

归档 RETFound 相关论文引用、官方实现信息、模型说明、版本与许可、输入预处理资料、迁移应用研究及实验设计。目前尚未归档具体资料或运行模型。

每项材料记录标题、作者或机构、官方来源链接、版本或代码提交、发布日期、获取日期、许可与项目用途。研究笔记区分原文事实、团队理解和待验证假设。

后续实验记录模型和权重版本、来源与校验值、数据授权与划分、预处理、运行环境、评价方法、实际结果和局限性。权重和原始数据放在仓库之外，不在此目录下载或复制大型文件。

模型接入实现将放在 `model_service/`；本目录提供研究依据，不代表已完成复现、效果验证或临床适用性评价。
