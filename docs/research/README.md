# 科研资料归档

本目录用于管理项目研究依据，当前仅建立归档说明，没有下载论文、模型权重或数据集。

- [retfound/](retfound/README.md)：RETFound 相关论文、官方实现、模型版本、许可与实验依据。
- [medical_kg/](medical_kg/README.md)：医学知识图谱、术语、知识来源和检索方案研究。

每份材料记录标题、作者或机构、来源链接、发布日期、获取日期、版本、许可和用途。论文原文、团队笔记、模型实验与医学专业意见应分别标识；不把未验证的推断当作已确认结论。

原始医疗数据、患者信息、受限资料和大型权重不上传到 Git。经许可可公开的资料与人工摘要应保留引用及版本，实验结果需关联方法、环境和验证记录。
