# 医学知识图谱研究资料

归档医学知识图谱、眼科术语、疾病与检查关系、可引用知识来源、检索方法和知识服务评估方案。目前不导入知识库或医学数据。

每项资料记录标题、作者或发布机构、来源链接、发布日期与版本、获取日期、许可、适用范围及人工复核状态。结构化知识应保留实体、关系、原始出处和更新时间，便于追溯和纠错。

团队笔记区分已引用知识、模型推断和专业人员意见；来源冲突与不确定性需明确记录。涉及医学解释或应用边界的内容由具备相应能力的人员复核。

知识服务实现将放在 `knowledge_service/`。患者信息、受限医学资料与未授权数据库不上传到 Git，经授权的公开资料仍需保留引用和许可信息。
