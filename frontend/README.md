# 前端工程规划

本目录预留给 RETFound 眼底智能分析平台前端。目前仅建立工程说明，不初始化框架、依赖或业务代码。

## 规划范围

- 分析任务创建、输入校验及任务进度展示。
- 模型结果与知识来源展示，明确区分模型预测、知识引用和人工意见。
- 结果复核及错误提示；具体页面、权限与交互由需求确认后确定。

## 后续启动条件

先在 `docs/competition/01_requirements/` 确认需求，在 `docs/competition/02_architecture/` 确认接口与数据流，再选择技术栈。演示图片需具备使用授权并完成脱敏；原始影像、凭据和患者信息不进入 Git。

实现时将会话、修改文件、生成成果、截图与验证结果关联到证据索引，并按实际工具分别记录 CodeArts 内置智能体和 OpenAI Codex 的贡献。
