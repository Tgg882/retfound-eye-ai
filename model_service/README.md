# RETFound 模型服务规划

本目录预留给 RETFound 模型接入与推理服务。目前不下载模型、不安装依赖、不编写推理或训练代码。

## 规划范围

- 明确模型版本、来源、许可、适用输入及预处理约定。
- 规划权重加载、推理调用、结果结构和资源需求。
- 设计可复现验证与异常输入处理；性能和模型效果须通过后续实验确认。

## 资料与产物管理

文献、版本与许可说明归档到 `docs/research/retfound/`。模型权重和原始数据集存放在 Git 仓库之外；仓库仅记录经审查的来源、版本、校验值和实验方法，不保存访问凭据。

服务契约及部署边界先在架构资料中确认。当前没有已运行的模型、性能指标或临床验证结果，不将规划描述作为实现证据。
